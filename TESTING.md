# Application Test Plan

This document outlines the test plan for the Medical Centers application to ensure all functionalities are working as expected.

## 1. Authentication

- [ ] **User Registration (Patient)**: Verify that a new patient can register successfully.
- [ ] **User Registration (Doctor)**: Verify that a new doctor can register successfully.
- [ ] **User Login (Patient)**: Verify that a registered patient can log in.
- [ ] **User Login (Doctor)**: Verify that a registered doctor can log in.
- [ ] **User Logout**: Verify that a logged-in user can log out successfully.

## 2. Navigation

- [ ] **Home Page**: Verify that the home page loads correctly and all navigation links are present.
- [ ] **City Page**: Verify that clicking on a city navigates to the correct city page.
- [ ] **Map Page**: Verify that the map page can be accessed and loads correctly.
- [ ] **Dashboard (Patient)**: Verify that a logged-in patient can access their dashboard.
- [ ] **Dashboard (Doctor)**: Verify that a logged-in doctor can access their dashboard.
- [ ] **Book Appointment**: Verify that a logged-in user can access the appointment booking page.

## 3. City and Center Display

- [ ] **City List**: Verify that the list of cities is displayed correctly on the home page.
- [ ] **Filter by Region**: Verify that filtering cities by region works as expected.
- [ ] **Medical Centers**: Verify that medical centers for a selected city are displayed correctly.

## 4. Map Functionality

- [ ] **Map Load**: Verify that the map loads without errors.
- [ ] **Center Markers**: Verify that medical centers are displayed as markers on the map.
- [ ] **Marker Popups**: Verify that clicking on a marker displays a popup with the center's information.

## 5. Appointment Booking

- [ ] **Access Control**: Verify that only logged-in users can access the appointment booking page.
- [ ] **Form Display**: Verify that the appointment booking form is displayed correctly.
